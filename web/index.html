Zero-cell correction: The diagnostic odds ratio and its log-normal confidence interval use the Haldane–Anscombe 0.5 correction for all four cells. Other metrics use the observed counts.

Methods: Wilson score 95% CIs for proportions; log-normal 95% CI for DOR. PPV/NPV reflect the study sample prevalence; post-test probabilities use the separate specified pre-test probability. Undefined estimates are displayed explicitly.

All calculations run in this browser with no API request or data upload. Do not enter identifiable patient information. Descriptive statistical tool; not a clinical decision rule.
